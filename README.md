# Bike Troubleshooting Assistant

A chatbot that answers motorcycle troubleshooting questions, grounded strictly
in official owner's manuals. Ask "bike won't start" or "what does the wrench
light mean" and it replies using only the selected bike's manual — never the
open web, and it declines anything off-topic.

**Bikes covered:** Hero Splendor Plus, Honda Shine, Bajaj Pulsar 150,
TVS Apache RTR 160 4V, Royal Enfield Classic 350.

**How it works:** each bike's manual is indexed separately using *contextual
retrieval* (Anthropic's technique — a short AI-written context line is added to
every chunk so it stays findable) and *hybrid search* (semantic + keyword).
Answers are generated by Sarvam's `sarvam-30b` model.

## Project layout

```
bike-chatbot/
├── manuals/          the 5 owner's-manual PDFs  (you add these)
├── storage/          generated search indexes   (created by ingest.py)
├── config.py         all settings in one place
├── sarvam_llm.py      Sarvam API wrapper
├── ingest.py         builds the per-bike indexes
├── app.py            the Streamlit chat app      (added in the next step)
├── requirements.txt
├── .env              your Sarvam API key         (you create this)
└── .env.example
```

## Setup

**1. Python 3.10+** — check with `python --version`.

**2. Put the 5 manuals in `manuals/`**, named exactly:
`splendor.pdf`, `shine.pdf`, `pulsar.pdf`, `apache.pdf`, `enfield.pdf`.

**3. Create a virtual environment and install dependencies:**
```bash
python -m venv .venv
# Windows:        .venv\Scripts\activate
# macOS / Linux:  source .venv/bin/activate
pip install -r requirements.txt
```
(The first install pulls PyTorch, so it may take a few minutes.)

**4. Add your Sarvam API key.** Copy `.env.example` to `.env` and paste your
key (from https://dashboard.sarvam.ai → API Keys):
```
SARVAM_API_KEY=sk_your_real_key_here
```

## Build the indexes

```bash
python ingest.py --no-context --limit 8   # 30-sec sanity check
python ingest.py --no-context --force     # full plain indexes (~2 min)
python ingest.py --force                  # final: contextual (slower, one-time)
```

Run `python ingest.py --help` to see all options.

## Run the app

Added in the next build step:
```bash
streamlit run app.py
```
